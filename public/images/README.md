# Silk Studio — Image Slots

Replace each placeholder file with the correct photo. The website code references these exact filenames, so keep the names the same.

## How to upload from iPad (GitHub web UI)

1. Open this folder on github.com → `seomasha/dzeni-test/public/images/`
2. Tap on the placeholder file you want to replace
3. Tap the pencil icon (Edit) or the "..." menu → choose **Replace** / **Upload**
4. Select your photo from your iPad
5. Commit the change

Vercel will auto-redeploy after each commit.

## Recommended image sizes

For best performance keep images:
- **Hero / About / Gallery large**: 1200–1600px wide
- **Service cards / smaller gallery**: 800–1000px wide
- Format: **JPG** (or convert PNG → JPG before upload)
- File size: ideally under 500 KB each
